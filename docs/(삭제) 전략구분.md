# 전략 구분안 — S1~S5를 관행형으로 재정의 + 신호 우선순위 (2026-08-29)

> 현재 구현을 무시하되 **5개 전략 아키타입(S1·S1a·S2·S3·S4·S5)은 유지**한다.
> 각 전략을 일반적인 퀀트 관행에 맞게 재정의하고, 이들이 내는 매수/매도 신호에 **우선순위를 매기는 방법**을
> 관행대로 설계한다.
> 관련: [`전략검토.md`](전략검토.md) · 백지 설계안 [`순수관행.md`](순수관행.md) · 현행 개선 [`전략변경계획.md`](전략변경계획.md)

## 1. 전제와 제약

- **데이터**: 웹서버(경량 DB)에 있는 것만 — 종목별 일봉 OHLCV + 지수(KOSPI·KOSDAQ·S&P500·USD/KRW). 수급·재무 미사용.
- **유니버스**: `target_stocks` 정적 목록. 시점(point-in-time) 유니버스 전환·생존편향 제거는 **하지 않는다**(감수).
- **스타일**: 롱온리, 일봉 스윙, 동시 보유 **5종**(슬롯 N=5).
- **신호·체결 (화면별)**:

  | 모드 | 신호 | 체결 | 거래비용 |
  |---|---|---|---|
  | 시뮬레이션(백테스트) | D-1 종가까지 | <span style="color:red">D-0 종가 체결(자동)</span> | 무시 |
  | 모의투자 | D-1 종가까지 | <span style="color:red">D-0 종가 체결 **제안**(사용자 확정)</span> | 무시 |
  | 투자제안 · 투자제안(모) | D-0 종가까지 | 없음 (추천 표시만) | 무시 |
- [`순수관행.md`](순수관행.md)와의 차이: 저 문서는 전략 개념 자체를 버리고 단일 합성 스코어로 간다. 이 문서는 **5개 전략을 남기고** 각각을 관행형으로 고친 뒤, 여러 전략이 동시에 신호를 낼 때 **무엇을 먼저 살지** 규칙을 만든다.

## 2. 요구사항 이해

현행 S1~S5의 관행 위반 지점:
- 신호가 종목 단독(횡단면 비교 없음).
- 진입 컨텍스트(추세·위치)가 약함 — 캔들패턴(S5)이 단독으로 매수.
- 문서/코드 불일치(S1 sma60 미사용).
- 전략 간 우선순위 = `prob_up` 정렬 하나뿐, 콤보는 무상관 OR.

→ 목표: **① 각 전략을 "추세 레짐 + 위치 + 확인"이 있는 관행형으로 재정의**, **② 전략 신호를 횡단면·컨펌 기반으로 서열화**.

## 3. 전략별 관행형 재정의

각 전략은 (종목, 날짜)마다 다음을 출력한다:
- `signal ∈ {enter, hold, exit}`
- `setup_strength` — 그 전략 고유의 셋업 강도 원값(예: 돌파 폭, 밴드 이탈 z, 패턴 점수)
- `stop` — ATR 기반 손절가, `setup_age` — 셋업 경과 봉수

| 키 | 아키타입(유지) | 관행형 정의 (OHLCV+지수만) | 대표 파라미터 |
|---|---|---|---|
| **S1** | 추세추종(이동평균) | `종가 > SMA200` **및** `SMA50 > SMA200`(정배열 레짐) **및** 20일 신고가 돌파. 청산: `SMA50` 하향 이탈 또는 샹들리에 스톱. `ADX(14) > 20` 추세강도 게이트. | SMA 20/50/200, ADX 20 |
| **S1a** | S1 + 거래량 | S1 조건 **+ 거래량 확인**: 돌파일 거래량 > 20일평균×1.5 **및** OBV 신고가. 그 외 S1과 동일. | vol×1.5, OBV |
| **S2** | 눌림목 돌파 | **상승추세 내 되돌림 후 재개**: 정배열 레짐에서 상승하는 20일선/직전 돌파레벨까지 눌린 뒤, 변동성 수축(볼린저 스퀴즈)·inside bar·NR7에서 5일 신고가 재돌파. | BB(20,2) 밴드폭 percentile, NR7 |
| **S3** | 볼린저/변동성 밴드 | **상승추세 내 평균회귀**: `종가 < 하단밴드(20,2)` **및** `종가 > SMA200` **및** `RSI(2) < 10` → 매수. 청산: 중심선 복귀 또는 `+kσ`. 레짐 필터로 하락장 매수 차단. | BB(20,2), RSI(2)<10 |
| **S4** | RSI | **모멘텀형으로 고정**(S3와 정체성 중복 방지): 상승추세에서 `RSI(14)`가 50을 상향 돌파(과매수 되돌림이 아니라 강세 진입). 청산: RSI 50 하향 또는 스톱. | RSI(14), 50 크로스 |
| **S5** | 캔들 패턴 | **지지선에서의 가격행동 반전**: 상승하는 50일선 또는 직전 스윙 저점 **위치에서** 상승장악형·해머·모닝스타 발생 + 다음 봉 확인. 패턴 단독 무효 — 반드시 추세·위치 컨텍스트 필요. | 패턴 사전, 위치 허용오차 |

공통 원칙(관행):
- 모든 전략에 **시장 레짐 게이트**: 추세형(S1/S1a/S2/S4)은 risk-on(KOSPI>200MA)에서만. 평균회귀형(S3/S5)은 중립까지 허용, 하락장 금지.
- 손절은 전 전략 **ATR 기반**(진입가 − k·ATR(14)).
- `setup_strength`는 뒤에서 횡단면 표준화됨.

## 4. 신호 우선순위 (관행)

여러 전략이 같은 날 여러 종목에 신호를 낸다. 슬롯은 유한하므로 서열이 필요하다. 4개 레이어.

### 레이어 1 — 적격 게이트 (모두 통과 못 하면 탈락)
- 시장 레짐(전략별 허용 조건, §3 공통 원칙).
- 유동성 하한: 20일 평균 거래대금·가격 하한.
- 최근 거래정지/상·하한가 없음.

### 레이어 2 — 종목 단위 신호 결합 (한 종목에 여러 전략이 동시 발화)
- 각 발화 전략의 `setup_strength` → **횡단면 백분위**(그날 같은 전략 발화 종목들 기준)로 변환.
- **종목 점수** = 발화 전략들의 백분위 가중평균
  - **+ 컨펌 보너스**: 서로 다른 패밀리 2개 이상 동의 시 +가산 (예: 추세(S1) + 거래량(S1a), 추세 + 패턴(S5)). = M-of-K를 종목 레벨에 적용.
- **패밀리 가중치**(관행): 추세/모멘텀 > 눌림목 > 평균회귀 > 패턴. 초기값은 이 서열의 고정 가중, 이후 각 패밀리의 아웃오브샘플 샤프로 워크포워드 조정.

### 레이어 3 — 종목 간 랭킹
- 적격 종목 전체를 종목 점수 내림차순 정렬.
- 섹터 상한(섹터당 최대 K종), 상관 상한 적용.
- 상위 **5종** 선택 → 변동성 타깃 비중 사이징(`w ∝ 1/σ`).

### 레이어 4 — 동점 처리 / 우선 규칙 (슬롯 부족 시 선착 순서)
1. 종목 점수가 높은 것.
2. 다중 전략 컨펌 > 단일 전략.
3. risk-on에서는 시장 방향과 같은 추세형 > 역추세형.
4. 저변동성 / 고유동성.
5. 셋업이 신선한 것(`setup_age` 작음).

### 매도 우선순위 (매일, 매수보다 먼저)
1. 하드 스톱(ATR) 도달.
2. **그 포지션을 연 전략**이 `exit` 신호.
3. 레짐이 risk-off 전환 → 역추세·고변동부터 축소.
4. 랭킹 이탈: 상위 2N 밖으로 밀림.
5. 최대 보유일 도달.

<span style="color:red">모드별: 시뮬레이션 = 위 매수/매도를 자동 체결. 모의투자 = 동일 시점·규칙으로 **매매를 제안**하고 사용자가 확정. 투자제안·투자제안(모) = 매수 후보·매도 사유를 **표시만**.</span>

## 5. 평가 방법 (관행)

- 전략별 아웃오브샘플 워크포워드로 **패밀리 가중치** 산출(샤프·프로핏팩터·회전율).
- 결합 포트폴리오 지표: CAGR·샤프·소르티노·MDD·Calmar·손익비·회전율·노출시간·KOSPI 대비 α/β. **거래비용은 반영하지 않는다**(전 모드 무시).
- 추천 화면에 각 종목의 발화 전략 + 종목 점수 백분위 + 컨펌 여부 표시.
- <span style="color:red">투자제안·투자제안(모)는 D-0 종가까지로 산출해 표시만. 모의투자는 D-1 신호 → D-0 종가 **체결 제안**. 시뮬레이션은 D-1 신호 → D-0 종가 자동 체결.</span>

## 6. 현행 대비 달라지는 점 (요약)

- S1~S5 존치하되 **전부 "레짐 + 위치 + 확인"** 구조로 재작성. S5 단독 매수 폐지.
- S4를 모멘텀형으로 고정해 S3와 정체성 분리.
- 전략 간 서열 = `prob_up` 정렬 → **4레이어(게이트 → 종목결합+컨펌 → 횡단면랭킹 → 동점규칙)**.
- 콤보 OR → 패밀리 가중 + M-of-K 컨펌 보너스.
- 균등 비중 → 변동성 타깃, ATR 스톱 + 최대 보유일.

## 7. 미결정 사항

1. 패밀리 가중치: 고정 서열 vs 워크포워드 학습.
2. 컨펌 보너스 크기, "다른 패밀리"의 정의(추세/거래량을 같은 패밀리로 볼지).
3. S4 정체성: 모멘텀 고정(권장) vs 과매수 되돌림 유지.
4. 슬롯 수 N → **결정: N=5**. 섹터 상한 K는 미정.
5. 최대 보유일 값, ATR 배수 k.
6. 레짐 게이트를 전략별로 다르게(권장) vs 전 전략 공통.
7. **결정**: 시점 유니버스 도입 안 함(생존편향 감수) · 거래비용 전 모드 무시.
8. <span style="color:red">**결정**: 신호·체결 — 시뮬레이션 D-1 신호→D-0 자동 체결, 모의투자 D-1 신호→D-0 **체결 제안**, 투자제안·투자제안(모) D-0 신호·체결 없음.</span>
