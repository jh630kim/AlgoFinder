# 계획 — 투자제안 / 투자제안(모)에 합성 점수 노출 (2026-08-30)

> 대상 화면: `/proposal`(투자제안), `/proposal-mobile`(투자제안 모바일). 공용 JS `static/js/proposal.js`.
> 배경: Phase 2로 순수관행 합성 점수(`CompositeScorer`)가 도입됐고 추천 응답에 `composite_pct`/`composite_rank`가
> 이미 흐른다([`진행결과.md`](진행결과.md) 참조). 이걸 화면 3개 목록에 마저 노출하고, 순위 상위 10종을
> 별도 섹션으로 보여준다.

---

## 1. 요구사항 이해

1. **매수추천 표(전략별 TOP 1~3) 아래**에 새 섹션 **"순수관행 합성 점수 TOP 10"** 을 추가한다.
   - 기존 매수추천은 "S1~S5 신호가 뜬 종목"만 나온다. 새 섹션은 **신호 유무와 무관하게 유니버스 전체를
     합성 점수로 정렬한 순위 1~10위**다 = [`순수관행.md`](순수관행.md) §5의 "매수 리스트: 상위 N종".
2. **보유 종목 표**에도 각 종목의 현재 **합성 점수·등수**(및 개시 전략)를 표시한다.
3. 기준일·모드(advice / sim)는 기존 추천과 동일하게 따른다(신호 판단일 기준).

현재 상태:
- 매수추천 표: 합성 점수% + 등수 **이미 표시됨**(`36b53f5`).
- 매도 시그널 카드: 합성 점수% + 등수 + 개시 전략 **이미 표시됨**(`36b53f5`).
- 보유 종목 표: 합성 점수 **없음** → 이번 추가.
- 합성 점수 TOP 10 섹션: **없음** → 이번 신규.

---

## 2. 할 작업

### 2-1. 백엔드 — 합성 점수 TOP-N 산출
- `ProposalAdvisor`에 "신호 판단일 시점, `cs_eligible` 종목을 합성 등수 오름차순으로 상위 N개" 반환하는
  메서드를 추가한다. 각 항목: 등수 · 종목코드 · 종목명 · 시장 · 합성 점수(백분위) · 기준일(D-0) 종가.
- 이미 계산해 둔 `_composite_map()`(창 단위 캐시)을 그대로 활용 — 추가 연산 없음.
- `/api/recommended-stocks` 응답에 `composite_top` 키(길이 10 배열)를 추가한다.
  프론트가 이미 이 엔드포인트를 1회 호출하므로 별도 엔드포인트·추가 fetch 불필요.

### 2-2. 백엔드 — 보유 종목에 합성 점수 부착
- `ProposalAdvisor.build_portfolio_view`가 이미 매도 시그널용으로 `_composite_map()`을 계산한다.
  그 값을 **각 보유 종목(`enriched`)에도** `composite_pct` / `composite_rank`(기준일 D-0 시점)로 붙인다.
- position dict에 이미 있는 `entry_strategy`도 `enriched`에 같이 실어 내려보낸다.

### 2-3. 프론트 — 합성 점수 TOP 10 섹션 (두 템플릿 + 공용 JS)
- **PC (`proposal.html`)**: 매수추천 `<section>` 바로 아래 카드 1개 추가.
  - 제목: **"🏅 순수관행 합성 점수 TOP 10"**
  - 표 컬럼: `순위` · `종목명 (코드)` · `시장` · `합성 점수 (백분위)` · `기준일 종가` · `[🛒 매수] [📊 차트]`
  - `<tbody id="compositeTopBody">`
- **모바일 (`proposal_mobile.html`)**: 매수추천(`#recBody`) 카드 아래에 같은 성격의 카드 + `<div id="compositeTopBody">`.
  항목은 모바일 카드 형태(순위 · 종목명 · 점수% · 종가 · 🛒매수 / 📊차트 버튼). **10행 그대로 노출**.
- **공용 JS (`proposal.js`)**: `render()`에서 `renderRecommendations` 다음에 `renderCompositeTop(rec.composite_top || [])`
  호출. 신규 함수는 `renderRecommendations`와 동일 패턴(PC 행 / 모바일 카드 분기, `wireRowButtons` 재사용).
  - 🛒 매수 버튼: `data-buy`의 전략 필드에 **`"순수관행"`** 을 실어 보냄 → `manual-buy`가
    `entry_strategy="순수관행"`으로 저장(백엔드 이미 지원).
  - 📊 차트 버튼: 기존 `data-chart` 방식 그대로.
- 빈 결과·로딩 문구는 기존 표들과 동일 스타일.

### 2-4. 프론트 — 보유 종목 표에 합성 점수 (`renderHoldings`, 두 템플릿)
- **PC (`proposal.html`)**: 보유 종목 표 헤더에 **"합성 점수"** 열 추가(위치: "현재가(선택일)" 다음).
  `renderHoldings` 행에 `NN.N% · N위` 표시. 빈 상태 `colspan` 9 → 10.
- **모바일 (`proposal_mobile.html`)**: 보유 카드에 한 줄 추가 — `합성 42% · 87위 · 매수: S3`.

---

## 3. 표시 정책

- TOP 10: 항상 10행(적격 종목이 10개 미만이면 있는 만큼).
- 합성 점수는 `NN.N%` + `N위` 병기(기존 매수추천 열과 동일 포맷).
- 이미 매수추천에 나온 종목이 TOP 10에 또 나올 수 있음 — **중복 제거하지 않음**(성격이 다른 목록).
- 보유 종목이 TOP 10 밖이면 등수만 크게 표시(예: `41.2% · 132위`).

## 5. 확정 사항 (2026-08-30)

1. **TOP-N = 10 고정.** 조절 UI 없음.
2. **팩터 기여 요약**("모멘텀 +1.8σ, 저변동 +1.2σ")은 **v2로 분리.** v1은 점수·등수만.
   (CompositeScorer가 현재 패밀리별 z를 밖으로 안 내보냄 → 노출부 추가는 후속.)
3. 신규 섹션 제목: **"🏅 순수관행 합성 점수 TOP 10"**.
4. 모바일 TOP 10: **10행 그대로 노출**(접기·더보기 없음).
5. 보유 종목 표에 **개시 전략(`entry_strategy`)도 함께 표시.**
