## 자율 결정 사항 (사용자 확인 없이 진행)

1. **`ohlcv-only` = `stage` 인자 값**으로 구현(별도 불리언 플래그 X). `MarketDataCollector.collect_target_market_data(ohlcv_only=)` 파라미터 추가, 기존 `_fetch_fdr_fallback`를 정식 경로로 승격. KRX rate-limit `sleep(0.5)`는 `ohlcv_only`일 때 생략.
2. **`roll_lite_db.py` 실패 판정**: 수집 중 예외 발생 **또는** `investor_trading_daily` 최신일이 안 늘어남 → `SystemExit(1)`. 워크플로는 `if: failure()`로 Discord 경고 + 기존 Release 자산 보존.
3. **경량 DB 2년치**: `--days` 기본값 `365 → 730` (`build_lite_db.py`, `roll_lite_db.py` 둘 다, 프루닝 창 포함). 이미지/Render 용량 여유 판단.
4. **STOP_LOSS_PCT/TAKE_PROFIT_PCT를 `backtest_engine` 모듈 상수로** 정의하고 `proposal_advisor`가 import — 순환 import 회피 + 단일 소스. 값(-5/+10)은 기존 그대로.
5. **`STRATEGY_COMBOS` 정리**: S1b/S1c 포함 8개(3·4·11·12·15·16·20·21) 제거, 남은 13개는 **번호 유지(결번)**. `backtest_engine` 상단 S1b/S1c import 라인도 제거(클래스 파일은 존치).
6. **순수관행 백테스트 엔트리(`combo_id`)**: **22** 사용(1~21과 충돌 없는 새 번호). `run_backtest_for_combo`가 아닌 **별도 모듈** `purerule_engine.PureRuleEngine`로 분리 — `backtest_engine` 비대화 방지 + 시뮬 규칙이 근본적으로 다름.
7. **순수관행 v1 사이징 = 균등 비중** (변동성 타깃 `w∝1/σ` + ±5%p 밴드 + "비중조정" 행은 **v2로 연기**). 이유: 부분 리밸런싱 회계를 자율 세션에서 정확히 검증하기 어려움. 대신 주간 전량 교체 + 즉시 편입으로 단순화. → [`순수관행.md`](순수관행.md) §8-2-B의 "더 단순한 대안"에 해당.
8. **순수관행 청산 규칙 구체값**: ATR(14) 하드스톱 배수 **2.5**, 트레일링 스톱은 v1 미구현(하드스톱+랭킹이탈+최대보유일로 충분히 규율), 최대 보유일 **30거래일**, 랭킹 이탈 버퍼 **2N(=10위)**, 리밸런싱 주기 = ISO 주차가 바뀌는 마지막 거래일.
9. **합성 점수 팩터 — 모멘텀은 6-1개월**(126-21거래일) 사용. 12-1개월은 데이터 창이 짧을 때 결측이 커서 [`순수관행.md`](순수관행.md) §8-4가 허용한 축소안을 채택. 팩터 패밀리: 모멘텀/추세품질/저변동/거래량(OBV 20일변화) 균등 1.0, 단기역추세 0.1. 윈저 1/99, 횡단면 z, 섹터 중립.
10. **유동성 게이트**: 가격 ≥ 1,000원 **and** 20일 평균 거래대금 ≥ 3억. 부적격 종목은 랭킹 최하위로 밀되 백분위·등수는 NaN.
11. **`prob_up` 표시 필드 처리**: 값을 제거하지 않고 **합성 백분위로 덮어씀**(추천 응답·매매일지 저장 필드 공통). 별도 `composite_pct`/`composite_rank` 필드도 추가. 전략 `calculate_indicators`의 `prob_up` 계산 자체는 건드리지 않음(수급 항 정리는 Phase 2 범위 밖 → 후속).
12. **화면 라벨**: `proposal.html`/`recommendation.html` 헤더 "상승 확신 확률 (%)" → "합성 점수 (백분위)". `backtest.html` 매매일지에는 해당 컬럼이 없어 변경 없음. `proposal.js`는 `r.prob_up` 값을 그대로 렌더(이제 합성 백분위) — **등수 별도 노출은 미반영(후속 JS 작업)**.
13. **`manual-buy` 전략 태그**: 요청 body의 `strategy`(또는 `entry_strategy`) 값을 저장, 없으면 `"MANUAL"`. 추천 카드 → 매수 연동 시 프론트가 전략 키를 함께 보내면 자동 기록됨(프론트 전달부는 후속).
14. **파일 크기**: `purerule_engine.py` 206줄로 CLAUDE.md 200줄 기준을 6줄 초과. `backtest_engine.py`(462줄, 사전 초과)와 함께 후속 리팩터 대상. 자율 세션에서 무리한 분할보다 동작 검증 우선.
15. **`git` 커밋 대상**: Phase별로 소스만 스테이징(생성 산출물 `data/`, `test_07_..._results.csv`는 제외). 브랜치 분기 없이 `master` 직접 커밋(저장소가 solo·master 워크플로).
