## Part B — 전략별 셋업 강도 (`setup_strength`)

각 전략의 `calculate_indicators`가 **`setup_strength` 컬럼**을 추가로 내보낸다.
"이 전략의 셋업이 이 종목에서 지금 얼마나 강한가"를 **그 전략 논지 기준**으로 재는 원값(클수록 강함).
신호가 없는 행은 `NaN`.

| 전략 | 논지 | `setup_strength` 원값 (예시) |
|---|---|---|
| **S1** | 골든크로스 추세 | `(sma5 − sma20) / sma20` (이평 이격 확대율) + `max(0, close/sma60 − 1)` (장기선 여유). 정배열이 벌어질수록 강함 |
| **S1a** | S1 + 거래량 | S1 원값 + `volume / MA20(volume) − 1` (거래량 급증분) |
| **S2** | RSI 시그널 크로스(과매도 후) | `(rsi − signal)` (크로스 폭) × `max(0, 35 − rsi_prev)` (직전 눌림 깊이). 깊게 눌렸다 강하게 반등할수록 강함 |
| **S3** | 볼린저 하단 반등 | `(bb_lb_prev − close_prev) / std` (밴드 이탈 깊이) × `1{close > sma200}` (추세 필터) × `(50 − rsi2)/50` (RSI(2) 낮을수록↑). 더 극단 과매도일수록 강함 |
| **S4** | RSI 30 탈출 | `max(0, 30 − rsi_min5)` (직전 저점 깊이) × `(rsi − rsi_prev)` (탈출 각도). 더 깊었다 빠르게 나올수록 강함 |
| **S5** | 지지선 반전 캔들 | `패턴 신뢰도(0~1)` × `1 − |close − 지지선| / (ATR14)` (지지선 근접) × `다음봉 확인 강도`. 위치·확인이 좋을수록 강함 |

- 원값의 절대 스케일은 전략마다 다르므로, **그날 그 전략이 발화한 종목 집합 안에서 백분위(0~1)** 로 변환해 쓴다(`setup_pct`).
- 표본 방어: 그날 발화 종목이 `< K`(예: K=3)면 백분위가 무의미 → 전부 중앙값(0.5)으로 처리.

## Part C — 우선순위 산출 (슬롯 배분)

여러 전략이 여러 종목에 신호를 낸 날, 슬롯(5개)에 넣을 순서를 정한다. 3단계.

### C-1. 전략별 백분위
- 각 발화 전략 X에 대해, X가 그날 신호 낸 종목들의 `setup_strength` → `setup_pct`(0~1).

### C-2. 종목 점수
한 종목이 여러 전략을 띄웠으면 그 전략들의 `setup_pct`를 결합:
```
name_score = Σ_over_firing_strategies ( family_weight[X] × setup_pct[X, 종목] )  / Σ family_weight
           + confirm_bonus        # 서로 다른 패밀리 2개 이상 동의 시 +b
           ( + α_blend × composite_pct/100  — 옵션, 아래 )
```
- **family_weight**: 초기 고정 서열 — 추세(S1·S1a) 1.0 > 눌림목/모멘텀(S2·S4) 0.8 > 밴드/평균회귀(S3) 0.7 > 패턴(S5) 0.6. 이후 각 패밀리의 **아웃오브샘플 워크포워드 샤프**로 조정.
- **confirm_bonus** `b`: 예 0.1. "추세 + 거래량"(S1+S1a)은 같은 패밀리로 봐서 보너스 제외.
- **composite 블렌드(옵션)**: `α_blend`(예 0.2)로 유니버스 합성 백분위를 **소량만** 섞어 품질 틸트. `α_blend = 0`이면 순수 전략구분 방식.

### C-3. 종목 간 랭킹 → 슬롯
- `name_score` 내림차순 정렬.
- 섹터 상한(섹터당 최대 2), 이미 보유 종목 제외.
- 상위 N(빈 슬롯 수)만 D-0 종가 체결.
- 동점: ① 다중 전략 컨펌 > 단일 ② 저변동 ③ 셋업 신선도(`setup_age` 작음).

### C-4. 백테스트·추천 배선
- `backtest_engine._simulate_trading`: 매수 후보 정렬 키를 **`composite_pct` → `name_score`** 로 교체.
- `proposal_advisor.get_recommendations`: 동일 정렬. 매수추천 표에 `합성 점수` 대신(또는 병기) **`셋업 점수 · 전략별 등수`** 노출.
- 순수관행 백테스트 엔트리(combo 22)는 **그대로** — 이건 신호 없이 순수 합성 랭킹이라 이 변경과 무관.

## Part D — composite 점수의 위치

이 변경 후 유니버스 합성 점수는:
- **선정 주 랭킹에서 빠지거나(α_blend=0), 소량 틸트로만(α_blend≈0.2)** 남는다.
- **화면 표시·순수관행 엔트리·보유 종목 모니터링**용으로는 계속 유지(합성점수표시.md 반영분).
- 즉 "전략 신호의 우선순위"는 전략 자체 셋업 강도로, "이 종목이 시장에서 팩터상 어디쯤인가"는 합성 점수로 — 역할 분리.

## 구현 순서

1. **Part A** 정리 먼저(삭제·문구) → 커밋. 기존 테스트 신규 실패 0 확인.
