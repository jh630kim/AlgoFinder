# 순수 관행안 — 가격·지수만으로 만드는 표준 퀀트 추천 시스템 (2026-08-29)

## 1. 전제와 제약

- **데이터**: 웹서버(경량 DB)에 있는 것만.
  - 종목별 일봉 OHLCV (시·고·저·종·거래량).
  - 지수 일봉: KOSPI, KOSDAQ, S&P500, USD/KRW (`market_indices_daily`).
  - 수급 주체별·재무·컨센서스 등은 **사용 안 함**.
- **유니버스**: `target_stocks`의 정적 목록(현 KOSPI200 + KOSDAQ150). 날짜별 시점(point-in-time) 유니버스로의 전환·생존편향 제거는 **하지 않는다**(생존편향은 감수).
- **스타일**: 롱온리, 일봉 기준 스윙, 동시 보유 **5종**(슬롯 N=5, 백테스트·투자제안 공통).
- **신호·체결 가정 (화면별)**:

  | 모드 | 신호 산출 | 체결 | 거래비용 |
  |---|---|---|---|
  | 시뮬레이션(백테스트) | D-1 종가까지 | D-0 종가 체결(자동) | 무시 |
  | 모의투자 | D-1 종가까지 | D-0 종가 체결 **제안** (사용자가 확정) | 무시 |
  | 투자제안 / 투자제안(모) | D-0 종가까지 | 없음 (추천 표시만) | 무시 |

## 2. 요구사항 이해

현행은 "종목별 이벤트 트리거(패턴 뜨면 매수) + 손튜닝 상수 + 미검증 확률 + 무상관 OR 콤보"다. 관행과 어긋나는 지점:

| 현행 | 표준 관행 |
|---|---|
| 종목 단독 계산 | **횡단면(cross-sectional) 팩터 랭킹** — 같은 날 전 종목을 한 척도로 정렬해 상위 롱 |
| 매직상수 스케일 | 롤링/횡단면 **표준화**(z-score), 윈저라이즈 |
| 균등 비중 | **변동성 타깃팅** 비중(리스크 균등) |
| 손절·시간청산 없음 | ATR 스톱 + 최대 보유일 + 포트폴리오 킬스위치 |
| "확률" 미검증 | **점수(백분위)** 표기 — 캘리브레이션 확률은 후속 옵션 |

→ 목표: **팩터 기반 횡단면 랭킹 + 레짐 필터 + 변동성 타깃 + 규율 있는 청산**으로 재설계.

## 3. 제안 설계

### 3-1. 팩터 세트 (전부 OHLCV/지수 파생)

관행적 스타일 팩터를 패밀리로 묶는다. 각 팩터는 "높을수록 매력적인 롱"이 되도록 부호 정렬.

| 패밀리 | 대표 지표(예) | 근거 |
|---|---|---|
| **모멘텀** | 12-1개월 수익률(최근 1개월 제외), 6-1개월, 52주 신고가 근접도, `종가/SMA200 − 1` | 중기 모멘텀은 가장 견고한 가격 팩터 |
| **추세 품질** | ADX(14), 로그가격 회귀 기울기·R², 상승마감일 비율 | 추세의 "깨끗함" |
| **저변동성** | 60/120일 실현변동성(역부호), 하방편차, KOSPI 대비 베타(저베타 선호) | 저변동 이상현상 |
| **단기 역추세(타이밍 오버레이)** | 5일 수익률 반전, RSI(2), 볼린저 %b, 20일선 이격(하단) | 진입 타이밍 보정용, 1차 팩터 아님 |
| **거래량 확인** | OBV 기울기(5~20일), 거래량/20일평균, CMF(20) | 매집/분산 방향 |
| **유동성·리스크 필터** | 20일 평균 거래대금, Amihud 비유동성, 가격 하한, 최근 거래정지/상·하한가 | 체결 가능성·꼬리위험 배제 |

### 3-2. 횡단면 스코어링 (코어)

매 거래일, 유니버스 전 종목에 대해:
1. 각 팩터 원값 계산.
2. **윈저라이즈**(1/99 percentile) → **횡단면 z-score**(그날 전 종목 기준).
3. **섹터 중립화**: 각 팩터 z에서 섹터 평균을 뺌(업종 편중 제거). 필요 시 사이즈 중립도.
4. **합성 점수** = 패밀리별 z의 가중합.
   - 가중치: 패밀리 **균등 고정**(1차 확정). 리스크 패리티·워크포워드 회귀는 후속 옵션.
   - 단기 역추세는 낮은 가중(예: 0.1)으로 타이밍만.

### 3-3. 시장 레짐 필터 (마켓 타이밍)

- **risk-on**: KOSPI > KOSPI 200일 이동평균 (1차 확정). 개별 종목 SMA200과의 듀얼 게이트는 후속 옵션.
- risk-off → 보유 종목 수 축소 / 현금 비중 상향 / 저변동 상위만 편입. 깊은 이탈(예: −10% 이하) 시에만 전량 청산.
- 보조 컨텍스트(선택): USD/KRW 급등, S&P500 < 200MA를 risk-off 가중으로.

### 3-4. 포트폴리오 구성

- 합성 점수 내림차순 → 상위 **5종** 선택.
- **비중 = 변동성 타깃팅**: `w_i ∝ 1/σ_i` (σ_i = 최근 실현변동성), 포트폴리오 사전 변동성이 목표치(연 12~15%)가 되도록 스케일.
- 단일 종목 상한(예: 25%), 섹터 상한(예: 40%), 상관 상한.
- **리밸런싱**: **주 1회 고정** — 목요일 종가 신호 → 금요일 종가. 이날 상위 5종 재선정(이탈분 매도·신규 편입), 변동성 타깃 비중 재조정.
- 비중 재조정 밴드: 상위 5종 유지 종목은 목표 비중 대비 **±5%p 이상** 틀어졌을 때만 재조정(자잘한 거래 방지).
- 주중(월~목)에는 §3-6의 예외 청산만 수행한다. 예외 매도로 빈 슬롯은 **다음 순위 상위 후보를 그날(D-0) 종가에 즉시 편입**한다(현금 방치 안 함). 편입 후보도 §3-6 레이어1 적격 게이트를 통과해야 한다.
- **모드별 처리**: 시뮬레이션 = 위 리밸런싱·편입을 자동 체결. 모의투자 = 동일 시점·규칙으로 **매매를 "제안"**(금요일 교체안, 주중 편입안)하고 사용자가 확정. 투자제안·투자제안(모) = 체결 개념 없이 D-0 종가까지로 산출한 "상위 5종"과 "청산 대상 보유 종목(사유 포함)"을 매일 갱신 **표시**만.

### 3-5. 리스크 관리

- **하드 스톱**: 진입가 − **2.5·ATR(14)** (ATR 배수 확정, 고정 % 안 씀).
- **트레일링 스톱**: 고점 − **3·ATR(14)**. 이익 구간 진입 후 상단은 이걸로만 관리. **고정 익절선은 두지 않는다**(승자는 달리게 둠).
- **최대 보유일**(예: 20~40거래일) 백스톱.
- 포트폴리오: 일일 손실 한도 / 낙폭 킬스위치 → 현금 디리스킹.

### 3-6. 청산 우선순위 (매일, 매수보다 먼저 평가)

1. 하드 스톱(진입가 − 2.5·ATR) 도달.
2. 트레일링 스톱(고점 − 3·ATR) 도달.
3. 랭킹 이탈 — 보유 종목이 상위 **2N(=10위)** 밖으로 밀림(확정. 1.5N=8위는 튜닝 여지).
4. 레짐이 risk-off로 전환 → 고변동·역추세부터 축소.
5. 최대 보유일 도달.
- 1~5는 주중에도 매일 평가한다. 시뮬레이션은 조건 충족 즉시 자동 청산·재편입, 모의투자는 청산·편입을 제안, 투자제안·투자제안(모)는 "매도 신호"로 표시만.

## 4. 평가 방법 (관행)

- **인샘플 팩터 선택 → 아웃오브샘플만 평가**. 롤링 워크포워드 창.
- 지표: CAGR, 변동성, **샤프·소르티노**, 최대낙폭, Calmar, 적중률, 손익비, 프로핏팩터, 회전율, 노출시간, KOSPI 대비 α/β.
- **거래비용은 반영하지 않는다**(전 모드 무시). 비용 drag·순비용 성과 지표는 산출 대상에서 제외.
- 확신도는 **점수(백분위)로 표기**한다(확정). isotonic/Platt 캘리브레이션 + 신뢰도 곡선은 후속 옵션.

## 5. 추천 화면 출력

- **매수 리스트**: 상위 5종 + 합성 점수(백분위) + 팩터 기여 분해("모멘텀 +1.8σ, 저변동 +1.2σ") + 제안 비중 + 스톱가 + 자연어 사유.
- **매도 리스트**: 청산 규칙에 걸린 보유 종목 + 어떤 규칙인지.
- 투자제안·투자제안(모)는 **D-0 종가까지**로 산출해 표시만. 모의투자는 D-1 신호 → D-0 종가 **체결 제안**. 시뮬레이션은 D-1 신호 → D-0 종가 자동 체결.
- 로컬·웹 동일 로직(둘 다 OHLCV·지수만 쓰므로 결과 일치).

## 6. 현행 대비 달라지는 점 (요약)

- 종목별 이벤트 트리거 → **횡단면 팩터 랭킹**.
- `prob_up` 시그모이드 → **합성 z-score 백분위(점수)**. 캘리브레이션 확률은 후속 옵션.
- 8개 전략 + OR 콤보 → **단일 합성 스코어** 한 개.
- 균등 비중 → 변동성 타깃.
- 손절 없음 → ATR 하드 스톱 + 트레일링 스톱(고정 익절 없음) + 최대 보유일 + 킬스위치.
- 매일 개별 신호 → 주 1회(금) 리밸런싱 + 주중 예외 청산(빈 슬롯은 즉시 재편입).
- 매직상수(1.5, 15, 25…) 전부 소멸.

## 7. 결정 사항 (2026-08-29)

1. 슬롯 수 N = **5** (백테스트·투자제안 공통).
2. 리밸런싱: 주 1회 고정 — 목요일 종가 신호 → 금요일 종가 + 주중 예외 청산.
3. 팩터 패밀리 가중: **균등 고정**(1차). 워크포워드 학습은 후속 옵션.
4. 레짐 필터: **KOSPI > 200일 이동평균** 단독(1차). 개별 종목 SMA200 듀얼 게이트는 후속 옵션.
5. 스톱: **ATR 배수** — 하드 `진입가 − 2.5·ATR(14)`, 트레일링 `고점 − 3·ATR(14)`. 고정 익절선 없음.
6. 확신도 표기: **점수(백분위)**. 캘리브레이션 확률은 후속 옵션.
7. 랭킹 이탈 버퍼: **상위 2N(=10위) 밖**. 1.5N(8위)은 튜닝 여지.
8. 주중 예외 매도로 빈 슬롯: **다음 순위 상위 후보 즉시 편입**(현금 방치 안 함).
9. 시점 유니버스: **도입 안 함**. 생존편향은 감수한다.
10. 신호·체결: **시뮬레이션** = D-1 종가 신호 → D-0 종가 **자동 체결**. **모의투자** = D-1 종가 신호 → D-0 종가 **체결 제안**(사용자 확정). **투자제안·투자제안(모)** = D-0 종가 신호, 체결 없음(표시만).
11. 거래비용: **전 모드 무시**.

### 튜닝 여지 (후속)
- 팩터 가중 워크포워드 학습 · 레짐 듀얼 게이트 · 이탈 버퍼 1.5N · 변동성 타깃 수준(12~15%) · 최대 보유일(20~40) · ATR 배수(2.5 / 3) · 캘리브레이션 도입.

## 8. 적용안 — 백테스트·모의투자·투자제안 4개 화면 반영 (2026-08-30)

### 8-1. 요구사항 이해

§1~§7의 순수관행 로직을 **전면 교체가 아니라** 기존 S1~S5 파이프라인 위에 얹는다. 합성 점수(§3-1·§3-2)를 계산하는 **공유 서비스**를 두고 네 갈래로 쓴다:

1. **백테스트**: 순수관행 방식 시뮬레이션을 리더보드 **신규 엔트리**로 추가(S1~S5와 병렬).
2. **백테스트 S1~S5(및 남은 콤보)**: 매수 후보를 빈 슬롯에 넣을 때의 **정렬 키를 `prob_up` → 합성 점수**로 교체. 신호는 불변, **정렬만**(게이트 아님).
3. **모의투자·투자제안·투자제안(모) 추천 리스트**: **합성 점수(등수)순 정렬**, 점수·등수 표시.
4. **위 세 화면의 매도 시그널**: 각 보유 종목에 **① 매수 시점 전략(S1~S5)** + **② 현재 합성 점수·등수**를 병기.

### 8-2. 할 작업

**A. 합성 점수 공유 서비스 (신규)**
- OHLCV+지수로 (종목, 날짜)별 합성 점수·백분위·등수 산출. §3-1 팩터 패밀리, §3-2 절차.
- 웹(경량 DB)은 데이터 창을 **2년치로 확장**(결정 8-3-3). 그래도 결측인 최장 팩터(12-1개월 모멘텀)는 창 앞부분에서 축소/제외.

**B. 백테스트 — 순수관행 엔트리 추가**
- **새 `combo_id`**(결번 재사용 안 함)로 리더보드에 1개 추가. `backtest_run` 재연산 목록에 포함.
- S1~S5용 시뮬레이터와 **별도 시뮬레이션 경로**: 상위 5종 by 합성 점수 · 주 1회(목→금) 리밸런싱 · ±5%p 비중 밴드 · ATR 하드(−2.5·ATR)/트레일링(고점−3·ATR) 스톱 · 최대 보유일 · 레짐 게이트(KOSPI>200MA) · 랭킹 이탈(상위 2N) 청산 · 주중 빈 슬롯 즉시 편입. 거래비용 무시.
- 매매일지는 **기존 스키마 재사용**(결정 8-3-6): 진입/청산 사유는 `strategy_tag`에 순수관행 어휘("랭킹편입"·"하드스톱"·"트레일링스톱"·"랭킹이탈"·"레짐오프"·"최대보유일"), 부분 비중 조정은 `strategy_tag="비중조정"` 행으로.

**C. 백테스트 — S1~S5 매수 정렬 교체**
- 후보 정렬을 `prob_up` 내림차순 → **합성 점수 내림차순**. 신호·나머지 로직 불변.
- <span style="color:red">S1~S5 백테스트 슬롯도 3 → **5로 통일**(결정 8-3-7). 리더보드 성과가 재산정된다.</span>

**D. 화면 — 정렬·표시 (표현 방식)**
- 모의투자/투자제안/투자제안(모) 추천 리스트: 합성 점수 내림차순 정렬. 각 행에 "합성 점수(백분위) · 등수 N/전체" 표시.
- **`prob_up`(확신도) 열 → 제목 "합성 점수(등수)"로 변경**, 값은 합성 점수 백분위+등수. 백테스트 매매일지 열도 동일. `prob_up` 자체는 계속 계산되나 화면·로그에는 노출 안 함(저장 필드엔 합성 점수 값을 채움).
- 매도 시그널 행: 기존 배지(전략매도/−5%/+10%) 옆에 "매수: S3" 형태의 **개시 전략 배지** + "합성 점수 42%ile · 87위" 형태 텍스트 추가.

**E. DB — 매수 전략 태그 저장**
- `paper_positions`에 **개시 전략 컬럼 추가**(예: `entry_strategy`). `paper_trade_histories` 매수행에도 기록.
- `create_all_tables()`의 paper_* 임시 마이그레이션 패턴과 동일하게 `ALTER TABLE ADD COLUMN` 처리.
- 매수 경로(추천 기반 매수, `manual-buy`)에서 전략 태그를 받아 저장. 순수관행 추천으로 산 종목은 `entry_strategy="순수관행"`.
