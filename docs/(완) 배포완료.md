## 3. 자동화

### GitHub Actions — `roll-lite-db.yml`
- 트리거: 평일 cron `30 9 * * 1-5` (UTC) = **18:30 KST** + 수동(`workflow_dispatch`)
- 흐름: Release `lite-db` 자산에서 `app_lite.db` 내려받기 → `roll_lite_db.py --skip-collect` (365일 밖 프루닝 + VACUUM) → Release 재업로드 → `RENDER_DEPLOY_HOOK_URL` POST(Render 재배포) → Discord 알림
- GitHub Secrets: `RENDER_DEPLOY_HOOK_URL`, `DISCORD_WEBHOOK_URL`
- GitHub Settings → Actions → Workflow permissions = **Read and write**
- Release: 태그 `lite-db`, 자산 `app_lite.db`

### UptimeRobot — 슬립 방지
- HTTP 모니터: `https://algofinder-vrrs.onrender.com/proposal-mobile`, 간격 **5분**
- Render 무료는 15분 유휴 시 슬립 → 5분 핑으로 상시 가동. 다운 시 이메일 알림 겸용.

### Turso — 가상매매 영속
- `prop` 매수/매도가 PC·폰·재배포와 무관하게 Turso에 저장됨.

## 4. 로컬(개발) 환경

- `.env` 를 비워두면 **지금과 100% 동일** (full 프로필, 20년치 `data/app.db`, 전체 화면, 동기화 버튼 활성).
- `.env` 에 `PAPER_DATABASE_URL` 을 넣으면:
  - 투자제안 화면에 **"⬆️ Turso로 보내기 / ⬇️ Turso에서 받기"** 버튼 활성
  - 로컬 Windows(Python 3.14)는 `sqlalchemy-libsql` 휠이 없어 드라이버 직접 연결은 불가 → 위 버튼은 **Turso HTTP API**(`/v2/pipeline`)로 동기화
  - `prop` 읽기/쓰기 자체는 여전히 로컬 `data/app.db` (동기화 버튼으로만 Turso와 교환)

### 폰 ↔ PC 가상매매 동기화 방법
1. 투자제안 화면의 **Turso 버튼** (전체 교체 + 직전 상태 백업 JSON 자동 다운로드)
2. 또는 **⬇️ 내보내기 / ⬆️ 불러오기** (JSON 파일 수동 이동)

## 5. 운영 방법

| 상황 | 조치 |
|---|---|
| 코드 변경 배포 | `git push origin master` → Render 자동 재배포 |
| 시세 데이터 갱신 | 자동(평일 18:30). 즉시 필요 시 GitHub → Actions → roll-lite-db → Run workflow |
| Turso 토큰 만료/무효 | Turso에서 토큰 재발급 → Render env `PAPER_DATABASE_URL` 교체 → 자동 재배포. 로컬 쓰면 `.env` 도 교체 |
| Render 수동 재배포 | 대시보드 → Manual Deploy → Deploy latest commit (또는 Deploy Hook URL POST) |
| 경량 DB 재생성(로컬) | `python deploy/build_lite_db.py` → Release `lite-db` 자산 교체 |

## 7. 미결 / 주의

- **PWA 아이콘 없음** — `static/manifest.webmanifest` 에 `icons` 없어서 "홈 화면에 추가"는 기본 바로가기만 됨(전체화면 앱 아님). 아이콘 192/512 PNG 2개 + 매니페스트 수정하면 "앱 설치" 활성화.
- **`roll-lite-db` 는 `--skip-collect`** (프루닝/VACUUM만). CI에서 KRX 수집이 확인되면 플래그 제거.
- **Render 무료 750시간/월** — 서비스 1개 상시 가동 ≈ 730시간(여유). 무료 서비스를 2개 이상 상시 가동하면 초과.
- **로컬 `.venv` Python 3.14** — `sqlalchemy-libsql` 설치 불가. 로컬에서 Turso 직접 연결이 필요하면 Python 3.12 venv 또는 WSL 필요(현재는 HTTP 동기화로 우회).
- **Actions 경고** — `actions/checkout@v4` / `actions/setup-python@v5` 가 Node 20 deprecated 안내(동작 무관). `@v5` / `@v6` 로 올리면 사라짐.
- **이전 실패 배포 잔여 테이블** — Turso에 빈 `all_stock_master` 등이 남아 있을 수 있음(무해, 원하면 대시보드에서 삭제).
